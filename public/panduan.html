NGULEMIN — Panduan Instalasi Lengkap

Dokumen ini ditujukan untuk pengguna yang membeli source code NGULEMIN dan ingin memasangnya dengan database Google Spreadsheet sendiri serta frontend sendiri di Vercel.

Penting untuk reseller: setiap pembeli sebaiknya memakai Spreadsheet, Google Apps Script deployment, dan project frontend milik sendiri. Jangan memakai URL API milik penjual jika database harus terpisah.

2. Cara Kerja Sistem

NGULEMIN terdiri dari frontend React/Vite dan backend Google Apps Script yang membaca serta menulis data ke Google Spreadsheet.

Website Vercel→Google Apps Script→Google Spreadsheet

Frontend

✓React + Vite
✓CMS Admin dan website publik
✓Konfigurasi API melalui public/config.js

Backend

✓Google Apps Script doGet()/doPost()
✓CRUD data CMS
✓Autentikasi admin berbasis token sesi

3. Buat Database Google Spreadsheet

1

Buat Spreadsheet baru

Buka Google Sheets dan buat spreadsheet baru. Nama yang disarankan: Database NGULEMIN.

2

Buka Apps Script dari Spreadsheet

Pada Spreadsheet pilih Ekstensi → Apps Script. Cara ini membuat project Apps Script terikat pada Spreadsheet tersebut, sehingga SPREADSHEET_ID pada source dapat dibiarkan kosong.

3

Jalankan inisialisasi

Setelah Code.gs dipasang, fungsi initDatabase() akan membuat/menyiapkan sheet seperti Settings, Home, Themes, Pricing, Features, Testimonials, HowToOrder, FAQ, Orders, Admin.

4. Pasang Code.gs

1

Hapus kode bawaan

Di editor Apps Script, hapus contoh myFunction() dan kode lama.

2

Paste Code.gs dari source package

Salin Code.gs dari source code NGULEMIN yang Anda beli dan tempel seluruh isinya ke editor Apps Script.

3

Simpan lalu jalankan initDatabase()

Pilih fungsi initDatabase pada toolbar Apps Script, lalu klik Run/Jalankan. Bila Google meminta izin, selesaikan otorisasi menggunakan akun pemilik database.

Hasil yang diharapkan:

Sheet database dibuat atau tetap dipertahankan. Fungsi inisialisasi tidak dimaksudkan untuk menghapus data yang sudah ada.

5. Deploy Google Apps Script sebagai Web App

1

Buat deployment

Klik Deploy → New deployment, lalu pilih tipe Web app.

2

Pengaturan deployment

PengaturanNilai yang disarankan
Execute asMe / User deploying (akun pemilik database)
Who has accessAnyone / anonymous access sesuai opsi yang tersedia di akun Google
URLGunakan URL produksi yang berakhiran /exec, bukan /dev
Kenapa akses publik diperlukan? Website publik mengirim request ke Web App Apps Script tanpa pengguna login ke akun Google. Google Apps Script memang menyediakan mode Web App dengan identitas eksekusi dan level akses yang dapat dipilih saat deployment. Dokumentasi resmi Apps Script Web Apps.
3

Salin URL /exec

Simpan URL tersebut. URL inilah yang nantinya dimasukkan ke konfigurasi frontend.

6. Atur API_URL pada Frontend

Pada project source NGULEMIN, gunakan public/config.js sebagai file konfigurasi URL API yang akan disajikan di root website.

const CONFIG = {
  API_URL: "https://script.google.com/macros/s/GANTI_DENGAN_URL_ANDA/exec",

  SITE_NAME: "NGULEMIN",
  TAGLINE: "Undangan Digital Elegan untuk Momen Istimewa"
};

if (typeof window !== "undefined") {
  window.CONFIG = CONFIG;
}
Jangan gunakan URL API penjual

Jika setiap pembeli harus memiliki database sendiri, URL API_URL harus menunjuk ke deployment Apps Script milik pembeli sendiri.

7. Deploy Frontend ke Vercel

1

Masukkan source code ke GitHub

Pembeli dapat memakai repository sendiri, atau repository yang diberikan sebagai bagian dari produk Anda. Pastikan perubahan public/config.js sudah dilakukan sebelum deployment.

2

Import project ke Vercel

Di Vercel pilih project GitHub lalu lakukan import. Project NGULEMIN menggunakan Vite dan memiliki script build npm run build.

3

Periksa hasil build

Status deployment harus Ready. File yang ditempatkan di folder public akan disajikan pada root URL; karena itu file panduan ini dibuat sebagai public/panduan.html agar dapat dibuka melalui /panduan.html. Dokumentasi resmi Vite.

9. Kelola Username & Password Admin

Versi backend NGULEMIN menyediakan menu khusus di Google Spreadsheet sehingga pemilik database tidak perlu mengubah hash password secara manual.

Spreadsheet→Menu NGULEMIN→Kelola Admin

Ubah Username

  1. Refresh/reload Spreadsheet setelah Code.gs tersimpan.
  2. Pilih menu NGULEMIN → Ubah Username Admin.
  3. Masukkan username baru.
  4. Login kembali setelah sesi lama dibatalkan.

Ubah Password

  1. Pilih NGULEMIN → Ubah Password Admin.
  2. Masukkan password saat ini.
  3. Masukkan password baru dan konfirmasi.
  4. Jangan mengedit PasswordHash secara manual.
Sangat disarankan: setelah instalasi baru, segera ganti password admin sebelum website diberikan kepada pemilik akhir.

11. Troubleshooting

Website putih/blank setelah deployment

Periksa Console browser (F12). Cari error merah pertama. Blank page biasanya merupakan error JavaScript saat runtime, bukan sekadar warning build.

Data masuk ke UI tetapi tidak muncul di Spreadsheet

Periksa URL API_URL, pastikan berakhiran /exec, pastikan Apps Script sudah dideploy ulang setelah perubahan Code.gs, dan pastikan akses Web App sesuai kebutuhan frontend.

Login lambat saat pertama kali

Google Apps Script dapat membutuhkan waktu saat instance sedang tidak aktif. Setelah itu, cache/sesi dan optimasi frontend mengurangi request berulang. Tunggu hasil login sebelum menutup halaman.

Perubahan baru belum langsung terlihat di website publik

Backend menggunakan cache publik untuk mempercepat pembacaan data. Setelah operasi CRUD, cache diinvalidasi oleh backend; lakukan refresh browser jika tampilan lama masih tersimpan di browser.

Password tidak bisa diubah dengan mengedit kolom PasswordHash

Benar. Kolom tersebut berisi hash. Gunakan menu NGULEMIN → Ubah Password Admin di Google Spreadsheet.

Catatan untuk Penjual Source Code

Pastikan seluruh aset pihak ketiga yang Anda distribusikan (gambar, font, ikon, audio, library, dan konten demo) memiliki hak/lisensi yang mengizinkan redistribusi kepada pelanggan. Panduan instalasi tidak menggantikan pemeriksaan lisensi masing-masing aset.
