Panduan Pemasangan & Deploy

1. Langkah Pasang Google Spreadsheet & Apps Script:

  1. Buka Google Sheets dan buat spreadsheet baru dengan nama Database NGULEMIN.
  2. Klik menu Ekstensi > Apps Script.
  3. Buka file Code.gs di project ini (atau salin dari textarea di bawah).
  4. Jalankan fungsi initDatabase satu kali untuk membuat seluruh sheet otomatis.
  5. Klik tombol Deploy > New deployment, pilih Web app, atur Who has access ke Anyone, lalu salin URL Web App yang berakhiran /exec.
  6. Paste URL tersebut ke tab Pengaturan Umum di atas atau ke config.js.

2. Langkah Deploy Frontend ke Netlify / Vercel:

  • Netlify: Buka app.netlify.com, drag and drop folder project ini ke Netlify Drop, website langsung live dalam 1 menit!
  • Vercel: Hubungkan repositori GitHub Anda ke Vercel atau gunakan perintah vercel deploy.
